# 🎬 Favorite Media Backend

This is the backend for my **Favorite Movies & TV Shows** web app — a small but powerful project I built to learn how real-world APIs work.

It’s built with **Node.js**, **Express**, **Prisma**, and **SQLite**.  
It lets you add, view, update, and delete your favorite movies or shows — all stored locally in a simple database file (no MySQL, no setup headaches).

---

## ⚙️ What it does

- Creates a REST API to manage movie and TV show data
- Validates all input using **Zod** (so bad data doesn’t break the app)
- Uses **Prisma ORM** to talk to an SQLite database
- Supports CRUD operations: **Create, Read, Update, Delete**
- Works perfectly with Thunder Client, Postman, or a frontend app

---

## 🧩 Tech Stack

- **Node.js + Express** – API server
- **Prisma ORM** – database layer
- **SQLite** – lightweight local database (no setup needed)
- **Zod** – for request validation
- **TypeScript** – because type safety saves headaches
